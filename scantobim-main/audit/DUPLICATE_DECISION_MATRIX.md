## Decision Principles

1. **Authoritative Single Source:** Every production module must have exactly one canonical path importable by Python and C#.
2. **Evidence-Based Selection:** Selection is strictly governed by production imports, Phase 1/2 compliance, test coverage, and feature completeness — never by filename, modification date, or file size alone.
3. **Zero Logic Loss:** Any useful, valid, or backward-compatible logic discovered in a duplicate candidate (e.g. `downsample_for_icp` in `registration_tools 2.py`) is merged into the authoritative file before deletion.
4. **Zero Regressions:** Pre-deletion test baselines must be captured and verified before any file deletion occurs.
