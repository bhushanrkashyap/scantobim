01 Gap Analysis — What's Detected Today

Current system detects 5 of 23 component types needed for a full building model

⚠️
Detection Coverage: 5 / 23 Component Types (22%)
Current Open3D pipeline: RANSAC detects vertical planes (walls/columns) and horizontal planes (floors/ceilings). DBSCAN detects cylinders (pipes). That's it. Doors, windows, beams, ducts, stairs, MEP equipment, cable trays, valves, fittings, and all external/civil elements are completely invisible to the current system.

03 Detection Algorithms Needed

7 new or upgraded algorithms to add to scan_tools.py to cover all component types

🔷
A1 — Floor vs Ceiling Separation (upgrade existing)
Upgrade
Current RANSAC finds all horizontal planes and calls them "floor". Add z-height context: planes near z=0 (± storey tolerance) = Floor; planes near z=storey_height = Ceiling. Requires storey height parameter (config or auto-detected from data).
Floor Ceiling Roof slab
↔️
A2 — Beam Detection (new)
New
After plane removal, run DBSCAN on residual points. Clusters with one dimension much larger than the other two AND z-centroid > 2m = Beam. Distinguish from pipes: beams have rectangular cross-section (hull aspect ratio >1.5), pipes are circular (aspect ratio ~1.0).
Structural beam Lintel Purlin
📦
A3 — Rectangular Box Detection for Ducts (new)
New
DBSCAN cluster post-processing: compute convex hull. If hull has 6 faces with near-orthogonal normals AND aspect ratio of two short dimensions is 0.5–2.0 = Rectangular duct. If aspect ratio >3 = Flat duct. Volume threshold separates duct from electrical panel.
HVAC Duct Duct fitting Cable tray
🚪
A4 — Opening Detection in Walls (new)
New
After RANSAC extracts a wall plane, project inlier points onto 2D plane. Rasterise to grid. Find rectangular voids (low-density rectangles) using connected-component analysis on the grid. Classify: if void bottom z < 0.2m = Door; if void bottom z > 0.6m = Window.
Door Window Curtain wall panel
🛤️
A5 — Sloped Surface Detection for Stairs/Ramps (new)
New
Extend RANSAC to track plane normal z-component: |z| > 0.93 = horizontal, |z| < 0.3 = vertical, 0.3 < |z| < 0.93 = sloped surface. Sloped planes: if smooth gradient = Ramp; if step-like z-discontinuities = Stair (detect by regulariy of height jumps).
Stair flight Ramp Roof slope
⚙️
A6 — Large Equipment Cluster Detection (new)
New
DBSCAN on residual points (after planes + cylinders removed). Clusters that are: large volume (>1m³) + roughly box-shaped + floor-touching = HVAC Equipment / Tank / Pump. Sub-classify by aspect ratio: tall cylinder = Tank; squat box = AHU; small box = pump.
AHU / FCU Tank / Vessel Pump
🕳️
A7 — Slab Opening / Void Detection (new)
New
Project floor plane inliers onto 2D grid. Apply morphological closing then find holes (connected regions of near-zero density surrounded by inlier points). Any hole >50×50mm = slab opening. Link to MEP elements passing through via z-stack analysis.
Stair opening Lift shaft MEP penetration
