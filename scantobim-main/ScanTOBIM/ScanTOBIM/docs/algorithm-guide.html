A Pre-Processing Algorithms

Clean and prepare the raw point cloud before any detection — always run first

A1
Voxel Grid Downsampling
Already implemented in scan_tools.py
Built
O(n) — very fast
How it works
Divides 3D space into uniform cubic voxels of side voxel_size. Replaces all points within each voxel with their centroid. Reduces point count by 10–100× while preserving shape. 10mm voxel is good for structural; 5mm needed for MEP fittings and valves.
Parameters
voxel_size0.01m (10mm) default — use 0.005m for valves/fittings
open3dpcd.voxel_down_sample()
Detects (enables)
  • All components

A2
Statistical Outlier Removal (SOR)
Remove noise points before detection
Missing
O(n log n)
How it works
For each point, computes the mean distance to its k nearest neighbours. Points whose mean distance is beyond std_ratio standard deviations from the global mean are removed as outliers. Eliminates scan noise, scanner multipath, and vegetation points that would confuse RANSAC and DBSCAN.
Parameters
nb_neighbors20 — number of neighbours to consider
std_ratio2.0 — points beyond 2σ are removed
open3dremove_statistical_outlier()
Why needed
Without SOR, RANSAC fits planes to noise clouds. DBSCAN creates false clusters from scattered points. A 2m scan range returns <1% noise, but 50m range returns 5–15% noise — enough to break detection.
# Add at start of pipeline
pcd, ind = pcd.remove_statistical_outlier(
  nb_neighbors=20,
  std_ratio=2.0
)
A3
Surface Normal Estimation
Required by RANSAC, Region Growing, and shape classification
Missing
O(n log n)
How it works
For each point, fits a plane to its k nearest neighbours using PCA. The smallest eigenvector is the surface normal. Normals are oriented consistently using a viewpoint (scanner position). Used to: classify plane orientation (vertical/horizontal/sloped), distinguish flat surfaces from curved, enable Region Growing segmentation.
Parameters
radius0.05m — search radius for normal estimation
max_nn30 — max neighbours for PCA

B Geometry Fitting Algorithms

Fit mathematical shapes (planes, cylinders, spheres, boxes) to point sets — the core of detection

B1
RANSAC — Iterative Plane Detection
Random Sample Consensus — already built
Needs Upgrade
O(n × iterations)
How it works
Repeatedly: (1) randomly picks 3 points, (2) fits a plane, (3) counts inliers within distance_threshold. Best plane wins. Inliers are removed, process repeats on residual (iterative RANSAC). Normal vector angle determines orientation:

|normal.z| > 0.93 → horizontal (floor/ceiling/roof)
|normal.z| < 0.30 → vertical (wall/column)
0.30 < |normal.z| < 0.93 → sloped (stair/ramp/roof slope)
Key Upgrade Needed
Add z-centroid context after plane extraction: floor vs ceiling separation using storey height. Add slope angle extraction for stairs/ramps.

B3
PCA — Principal Component Analysis
Extract primary axes, orientation, section profile from point clusters
New
O(n) — very fast
How it works
Computes the covariance matrix of a point cluster, then finds its eigenvectors. The 3 eigenvectors = the 3 principal axes; eigenvalues = variance along each axis.

Uses in Scan-to-BIM:
• Eigenvalue ratio → shape: λ₁≫λ₂≈λ₃ = linear (beam/pipe); λ₁≈λ₂≫λ₃ = planar; λ₁≈λ₂≈λ₃ = spherical
• Largest eigenvector = span direction of beam or pipe run
• Smallest eigenvector = normal of a flat element
• Middle eigenvalue ratio → distinguish rectangular from circular cross-section
numpy.linalg.eigh()sklearn PCA
Detects
  • Beam span direction
  • Column orientation
  • Pipe run direction
  • Duct axis
  • Shape type (linear/planar/spherical)
def pca_shape(pts):
  cov = np.cov(pts.T)
  eigenvalues, eigenvectors = np.linalg.eigh(cov)
  idx = np.argsort(eigenvalues)[::-1]
  λ = eigenvalues[idx]
  linearity = (λ[0]-λ[1]) / λ[0]
  planarity = (λ[1]-λ[2]) / λ[0]
  return linearity, planarity, eigenvectors[:,idx]
B4
Oriented Bounding Box (OBB)
Minimum volume box aligned to object axes — better than AABB
New
O(n log n)
How it works
Unlike Axis-Aligned Bounding Box (AABB), an OBB is rotated to fit the object tightly. Computed from PCA: rotate points to PCA frame → compute AABB in that frame → rotate back. Result: length, width, height along object's own axes, plus orientation quaternion.

Critical for beams and ducts: a diagonal beam's AABB is huge and misleading. Its OBB correctly gives span length × section width × section height.
Shape from OBB dimensions
L ≫ W ≈ H→ Beam, pipe, column, cable tray
L ≈ W ≫ H→ Floor, ceiling, flat duct, panel
L ≈ W ≈ H→ Equipment, tank, pump, column capital
open3dget_minimal_oriented_bounding_box()
Detects

  • Equipment (cube-ish)
  • Column section profile

C Clustering Algorithms

Group residual points into object candidates after plane extraction

C1
DBSCAN — Density-Based Clustering
Already built — needs parameter tuning for MEP
Needs Upgrade
O(n log n) with KD-tree
How it works
Groups points where: a point is a core point if it has ≥ min_points neighbours within radius eps. Core points form clusters; border points join nearest cluster; remaining = noise.

Two passes needed:
Pass 1: eps=50mm, min_pts=100 → large MEP objects (equipment, tanks, large ducts)
Pass 2: eps=20mm, min_pts=30 → medium MEP (pipes, beams, small ducts)
Pass 3: eps=10mm, min_pts=15 → fine detail (valves, fittings) on 5mm voxel cloud

C2
Region Growing Segmentation
Grow segments from seed points by normal + curvature similarity
New
O(n log n)
How it works
Starts from a seed point (lowest curvature = most planar). Grows by adding neighbours whose normal angle differs by < angle_threshold and curvature < curvature_threshold. Stops when no more neighbours qualify.

Advantage over RANSAC: finds non-planar curved surfaces (HVAC duct bends, tank domes, stair soffits) that RANSAC misses. Also segments walls with multiple patches as one region.
Parameters

max_cluster_size1,000,000 points
smoothness_threshold3.0° normal angle
curvature_threshold1.0

C3
Euclidean Cluster Extraction
Simple distance-based clustering — fast for isolated objects
New
O(n log n)
How it works
Groups points that are within a fixed distance of each other (like DBSCAN without the min_points requirement). Uses KD-tree for fast nearest-neighbour queries. Faster than DBSCAN, works better for isolated objects (pumps, panels, equipment) that have a clear gap to surrounding structure. Less good for touching surfaces.

from scipy.spatial import cKDTree

def euclidean_clusters(pts, tol=0.02, min_sz=50):
  tree = cKDTree(pts)
  visited = set()
  clusters = []
  for i, pt in enumerate(pts):
    if i in visited: continue
    members = tree.query_ball_point(pt, tol)
    clusters.append(members)
  return [c for c in clusters if len(c)>=min_sz]

D 2D Raster Analysis Algorithms

Project 3D plane points to 2D grid — find voids (doors/windows/openings) and patterns (stairs)

D1
2D Grid Rasterization + Void Detection
Find door/window openings in wall planes
New
O(n) + O(grid²)
How it works
After RANSAC extracts a wall plane:
1. Project inlier points onto the plane's 2D coordinate frame (u, v axes)
2. Rasterise to a 20mm grid — mark cells with points as "solid"
3. Find rectangular regions of empty cells surrounded by solid cells = opening
4. Classify by void bottom z: sill_z < 0.2m = Door; sill_z > 0.5m = Window
5. Extract width, height, sill height from void bounding box
Parameters
grid_resolution0.02m (20mm) — balance detail vs speed
min_void_area0.4m² — minimum opening size
door_sill_max0.2m — door sill below this
window_sill_min0.5m — window sill above this

D2
Morphological Operations (Closing / Opening)
Clean up raster grids — fill scan gaps, separate touching voids
New
O(grid² × kernel)
How it works
Dilation: expands solid regions by a kernel — fills scan gaps and thin cracks
Erosion: shrinks solid regions — removes thin noise
Closing (dilate then erode): fills small holes in walls without changing overall shape
Opening (erode then dilate): removes thin noise protrusions

Used in both wall void detection (D1) and slab opening detection. Scan data has gaps at window frames, door frames, wall junctions — closing fills these before void detection.

D3
Z-Profile Analysis for Stairs
Detect regular step pattern in z-direction from sloped plane points
New
O(n log n)
How it works
After RANSAC finds a sloped plane (0.3 < |normal.z| < 0.93):
1. Extract z-values of all inlier points
2. Build z-histogram with bin width = 10mm
3. Find peaks in histogram — peaks = tread surfaces
4. If peaks are regularly spaced (riser height tolerance ±15mm) = Stair
5. If no peaks (smooth z distribution) = Ramp

Riser height = mean peak spacing. Tread depth = width of each peak.
numpy (histogram)scipy.signal.find_peaks
Detects
  • Stair (peak pattern)
  • Ramp (no peaks)
  • Roof slope
  • Sloped slab
from scipy.signal import find_peaks

# Z-histogram of sloped plane inliers
z_vals = pts[inliers, 2]
hist, bins = np.histogram(z_vals, bins=200)
peaks, props = find_peaks(hist, distance=15, height=50)

spacings = np.diff(bins[peaks])
regular = np.std(spacings) < 0.015 # ±15mm
shape = "STAIR" if regular else "RAMP"

R-Tree Spatial Index
Fast bounding-box proximity queries for relationship building
New
O(log n) per query
How it works
Indexes bounding boxes in a tree structure. Query: "which elements intersect or are near this bounding box" runs in O(log n) vs O(n) brute force.

E2
Graph-Based Connectivity (Pipe Run Tracing)
Build pipe/duct system topology from detected segments
New
O(n + e) — n=segments, e=connections
How it works
Builds a graph where nodes = detected pipe/duct segments and edges = connections (endpoints within 100mm of each other).

Connected components = pipe systems. Each component is assigned a system type based on its connected equipment (near AHU = HVAC; near plant room = domestic water).

Traversal from equipment node identifies supply vs return vs drain paths.
