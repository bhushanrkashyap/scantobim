01 System Overview
What is Scan-to-BIM?

An AI-driven agent pipeline that converts raw point cloud scan data (E57/LAZ) into safety-classified BIM elements in Autodesk Revit. Designed for nuclear and critical infrastructure facilities where safety compliance (NQA-1, DSEAR, ISO 19650) is non-negotiable.

What does the PoV prove?
CapabilityEvidence
AI reads point cloudsOpen3D RANSAC plane detection + DBSCAN clustering extracts walls, floors, columns, pipes from scan data
Safety classification worksRule-based engine classifies SC1/SC2/SC3/NS. SC1 hard-blocked. SC2 requires human approval.
Audit trail is tamper-proofEvery action recorded in HMAC-SHA256 chained ledger. Chain integrity verifiable on demand.
Faster than manual25+ elements classified and dispatched in under 1 second vs. hours of manual work

03 Safety Classification Matrix

SC1

Safety-Critical

Containment, radiation shielding, reactor structure

HARD BLOCK
Never auto-create

SC2

Safety-Related

Load-bearing near safety zones, fire barriers, DSEAR

APPROVAL REQUIRED
Human sign-off

SC3

Safety-Relevant

Structural near safety systems, MEP in classified areas

FLAGGED
Auto-proceed

NS

Non-Safety

Standard elements, no safety implications

AUTO-PROCEED
No restrictions

Non-Negotiable Constraint SC1 elements must NEVER be auto-created by the agent. The system raises SafetyCategoryViolationError and logs an ELEMENT_BLOCKED audit event. There is no override, no bypass, no exception.

11 Demo Walkthrough
5-Minute Demo Script Run python demo.py for the narrated version. Below is what each step shows and why it matters.
1
Create Session

A new session is created for "Demo Nuclear Facility — Unit 4". This generates a unique session ID and starts the audit trail. The session tracks all segments, elements, clashes, and NCRs.

Session ID: bc415163-7c70-4e9e-a12f-809ac2bef3de Site: Demo Nuclear Facility — Unit 4

Shows: Session management, unique ID generation, audit trail initialisation.

2
Point Cloud Segmentation

AI processes the scan data and extracts geometry segments. In the PoV this uses synthetic data; in production it would load E57/LAZ files and run RANSAC plane detection + DBSCAN clustering via Open3D.

Segments found: 27 plane_vertical: 20 (walls + columns) plane_horizontal: 5 (floors) cylinder: 2 (pipes)

Shows: The AI extracts meaningful building elements from raw scan data — walls, floors, columns, pipes.

3
Safety Classification

Each segment is classified by element type, discipline, and safety category. The classifier detects one potential containment wall (SC1), one low-confidence structural column (SC2), and flags pipes and large walls (SC3).

SC1: 1 element — Containment wall. WILL BE BLOCKED. SC2: 1 element — Structural column. WILL REQUIRE APPROVAL. SC3: 5 elements — Flagged but auto-proceed. NS: 20 elements — Standard. Auto-proceed.

Shows: AI safety classification with four severity levels per NQA-1 standards.

4
Execute with Safety Gates

The agent attempts to create all 27 elements in Revit. The safety gate system intervenes:

Elements created: 25 ← NS + SC3 auto-created Elements blocked: 1 ← SC1 HARD BLOCKED (wall) Pending approval: 1 ← SC2 gate raised (column) Errors: 0

Shows: Safety gates in action. SC1 physically cannot be created. SC2 pauses for approval. NS/SC3 proceed.

5
SC2 Safety Gate Approval

A senior engineer reviews the SC2 gate and approves it. The element is then created with the approval signature attached. In production, this would be a Teams Adaptive Card.

Gate bb9b4f7a... — column segment 21facbc7... → APPROVED by senior.engineer@example.com → Element created: revit-1a96f5fe

Shows: Human-in-the-loop approval for safety-related elements. Gate ID, approver, and element ID all recorded.

6
Audit Chain Verification

The tamper-proof audit trail is verified. Every event is linked to the previous via HMAC-SHA256. Any tampering would break the chain.

Total audit events: 57 Chain integrity: PASS Audit events by type: element_blocked: 1 ← SC1 block recorded element_created: 26 ← 25 auto + 1 after SC2 approval safety_gate_approved: 1 safety_gate_raised: 1 segment_classified: 27 session_started: 1

Shows: Complete, verifiable audit trail. Every action traceable. Chain integrity proves no tampering.

12 Troubleshooting
IssueSolution
ModuleNotFoundError: agent Run from the ScanToBIM/ directory, not agent/. Python needs the parent directory in the path.
open3d installation fails Use pip install open3d-cpu on headless servers. Or skip Open3D entirely — the demo uses synthetic data.
Port 8765 already in use lsof -i :8765 to find the process. Kill it or use --port 8766 instead.
Audit chain shows valid: false Database may be corrupted. Delete scantobim.db and restart. Chain integrity is per-session.
GPT-4o classification not working Check OPENAI_API_KEY is set in .env. System automatically falls back to rule-based if unavailable.
demo.py shows 0 blocked / 0 pending The injected SC1/SC2 segments need the updated demo.py. Make sure the SC1 wall (10000x4000mm, 8000pts) is present.
Revit bridge connection refused Expected in PoV — system mocks Revit responses automatically. Real bridge connects in Stage 2.
