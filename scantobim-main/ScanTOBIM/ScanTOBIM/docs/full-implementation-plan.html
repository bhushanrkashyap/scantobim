06 AI Engine Strategy

Current and planned AI/ML components with cost, risk, and capability tradeoffs

Engine Role Status Cost When to Use
Open3D RANSAC Plane detection (walls, floors) Built Zero Always — default segmentation
Open3D DBSCAN Cylinder / pipe cluster detection Built Zero Always — residual point clustering
Rule Engine NQA-1 safety classification Built Zero Always — deterministic, no API calls
GPT-4o (OpenAI) LLM safety reasoning Built ~$0.01/element Set OPENAI_API_KEY — SC2+ edge cases
Azure OpenAI Enterprise GPT-4o (data residency) Near-Term ~$0.01/element When UK data sovereignty required
XGBoost / ONNX Trained safety classifier Mid-Term Zero (inference) After 500+ labelled training examples
LLM API Coordinator / Checker agent reasoning Mid-Term Per-token Agentic orchestration, complex decisions
ICP / Registration Multi-station scan alignment Near-Term Zero Multi-station scan sessions
Computer Vision Material classification from RGB scan Future GPU required When scanners provide colour data
